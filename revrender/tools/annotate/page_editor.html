标注规则

  1. 只标让字作废的痕迹：划线和涂黑。下划线、圈、箭头、着重号都不算。
  2. 划线（2）：沿着划线拖一下画一段。划线压到字的笔画时就停，跳过这个字，在字后面再拖下一段——画出来的就是要去掉、又不伤字的那部分。弯的线：画几段，点选相邻两段按 C 连成一条。
  3. 涂黑（1）：拖一个框盖住涂黑的墨迹；形状不规则就拖边上的小圆点，多出一个角。框里的墨迹会全部去掉。
  4. 组成一处：同一处涂改的几笔（几条线、几块涂黑），点选它们按 G。点一下选一笔，再点别的笔加进来，再点一次取消。按 U 把选中的笔拆出来。
  5. 作废区域（虚线框）：每一处自动算出被它作废的那些字的范围。不对就点虚线框选中，拖白点调整；调过的不会再自动变，按 R 重新算。
  6. 拖白点改形状；拖边中间的小圆点加一个点；按住 ⌥/Alt 点白点删掉它。
  7. 做完一题点「本题完成 ✓」。页面自动保存在这个浏览器里；换浏览器或电脑前先「导出」，到那边「导入」。
