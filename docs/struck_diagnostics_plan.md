# 诊断实验方案：VLM 读不出被划内容，瓶颈在哪里

2026-10-11 起草，交给执行者实现并运行。本文件只是方案：不改标注、不训练、不碰测试集。执行时如需偏离，先在本文件末尾「变更记录」写明原因，再动手。

---

## 0. 一页摘要

**要回答的问题**：学生手写数学作答里被划掉的内容，现成 VLM 为什么读不准？是"划线和原字叠在一起、分不开"（分离问题），还是 VLM 本身就认不好这些手写字（识别问题）？如果划线被完美分开，"擦掉"和"保留但标出来"哪种更好？整道题的上下文有没有帮助？

**做法**：用用户已经标好的「像素分离 + 被划文字」数据（216 处），把同一处修改做成 8 种图像版本（原图、理想擦除、理想标记、全部涂白、两种模型预测的擦除 / 标记等），配 3 种输入范围（小块、整行、整道题），让 4 个不同系列的现成 VLM 去读，与人工答案按字符对齐打分。

**不做什么**：不训练任何模型；不使用测试集（第一篇测试书写者的任何区域）；不修改任何标注文件。

**产出**：每个模型 × 版本 × 范围的读回率、严格全对率等，带置信区间；按 §8 预先登记的规则给出结论，决定论文方法往哪个方向做。

**三种可能结论及其含义**（详见 §8）：

| 结论 | 含义 | 论文方法方向 |
|---|---|---|
| 理想擦除比原图高很多 | 瓶颈是划线与原字分不开 | 做更准的笔画分离（再擦除或标记） |
| 理想标记明显好于理想擦除 | 擦除会伤字，保留信息更好 | 做"不擦除、把分离信息交给 VLM"（标记 / 注入） |
| 即使完美分离也读不准 | 瓶颈在 VLM 认手写数学本身 | 重点转向用我们的数据微调 VLM，数据集贡献为主 |

## 1. 背景与假设

论文的核心问题（2026-10-11 与用户确定）：被划掉的内容记录了学生"原来怎么做"，判断一次修改是纠错还是改错必须先读出它；现有 VLM 既读不准，也分不清它和最终答案；擦除类方法会连带毁掉原字。

本轮验证以下假设（H4 属第二阶段，见 §12）：

- **H1 问题存在**：现成 VLM 在原图上读被划内容的读回率低、严格全对率很低。
- **H2 分离是主要瓶颈**：把划线精确去掉（用人工像素标签）后，读回率显著提高。
- **H3 保留优于擦除**：在分离完美的前提下，"把划线标成另一种颜色、原字保留"比"擦掉划线"读得更准（擦除会擦伤交叉处的原字笔画）。
- **H3′ 现有分离方法的差距**：第一篇检测模型、我们的纯合成框内模型做出来的擦除 / 标记，与理想版本差多少，即方法的提升空间。
- **H5 整题上下文有帮助**：输入整道题比只给小块读得更准，且这不只是"模型从上下文猜出来的"（用全部涂白的对照扣除猜测成分）。

## 3. 变量一：图像版本（8 种）

所有版本都从同一张底图（§2）出发，只改目标区域，**同一页上的其他修改一律不动**。下文"多边形"指该处的 `region`，"划线像素"指 `runs` 解码后的像素（§2.1）。

| 代号 | 名称 | 怎么做 | 适用 |
|---|---|---|---|
| R | 原图 | 不改 | P、V |
| B | 全部涂白 | 多边形内所有像素设为 255（划线和原字都没了），用来测"模型靠上下文猜"的下限 | P、V |
| E\* | 理想擦除 | 划线像素设为 255 | P |
| M\* | 理想标记 | 划线像素改成红色 RGB(215, 40, 40)，其余像素不变 | P |
| E^p1 | 第一篇擦除 | 第一篇 RevRender（已收紧到墨迹）的实例掩膜并集，与"多边形外扩 3 像素"相交的部分设为 255 | P、V |
| M^p1 | 第一篇标记 | 同上像素改成红色 | P、V |
| E^syn | 纯合成框内模型擦除 | 纯合成训练的框内模型在该处的预测掩膜，与"多边形外扩 3 像素"相交的部分设为 255 | P、V |
| M^syn | 纯合成框内模型标记 | 同上像素改成红色 | P、V |

细节：

- **红色的取值**：底图是灰度图，标记版本输出 RGB；只把划线像素（灰度 < 245 的那部分，`runs` 本身已只含墨迹）改成红色，浅色的抗锯齿边缘不改。
- **第一篇掩膜**：`/home/zsh/hme/outputs/paper2_pages_clean_run_unlabeled3976_tight/<image_id>.json/.npz`，用 `revrender.pages.read_output` 读出实例，每个实例的 `mask` 铺回整页后取并集。
- **纯合成框内模型**：`/home/zsh/hme/outputs/paper2_strokes_boxes/formal/step_8000.pt`（没有用任何真实精修数据训练，见 RESULTS「纯合成框内模型补评」）。调用方式与统一评测一致：`revrender.box_remover.read_boxes(model, {'mask_threshold': .4, 'nms': .5, 'score_threshold': 0}, grey, [crop_of(region, size)], top=1)`，`crop_of` 来自 `revrender.box_remover`（框外扩 `PAD = 6`）。
- **不用**真实精修微调过的模型（`paper2_pixel_finetune20261007/formal/step_800.pt`、`paper2_pixel_round_group20261010` 的 step400）：它们训练时用过 P 里的区域，在 P 上测会泄漏。如想看它们，只能在 V 和 P 的 16 处验证区域上单独报告，不进判定。
- **每处另记统计量**（用于分组分析）：划线像素数、多边形内总墨迹像素数、划线占比（前者 / 后者）、`annotationMode`、`text` 长度、是否含公式（含 `$`）、是否用户新增框。

## 4. 变量二：输入范围（3 种）

所有范围都在图上**画一个蓝色矩形框**标出目标位置：颜色 RGB(0, 90, 255)，线宽 2 像素，位置为多边形外接矩形向外扩 3 像素（不压到框内笔画）。蓝框在图像版本（§3）处理完之后再画。

| 代号 | 范围 | 裁切方式 |
|---|---|---|
| S1 | 小块 | 多边形外接矩形向外扩 12 像素（保证蓝框在图内），裁到页面内 |
| S2 | 整行 | 见下 |
| S3 | 整道题 | 整张作答图（一处修改所在的那一张） |

**S2 整行的取法**（用第一篇的行切分，不需要人工）：

1. 读第一篇输出里的行：`paper2_pages_clean_run_unlabeled3976_tight/<image_id>.json` 的 `lines[]`，每行有 `box`（像素坐标）和 `source`（`ocr` / `ink`）。执行时先确认这个目录的 `lines` 与 `revrender.pages.write_page` 的格式一致。
2. 选出与目标外接矩形**纵向重叠 ≥ 两者中较矮者高度的 50%** 的所有行。
3. 把这些行的框与目标外接矩形取并集，再向外扩 12 像素，裁到页面内。
4. 一行都没选到时：取目标外接矩形上下各扩其高度的 50%、左右扩到整页宽度。
5. 每处记录用的是哪条规则、选了几行。整行范围里同时包含其他修改是正常的，不处理。

**可选 S0（只给 OCR 模型用，见 §6）**：多边形外全部涂白、只留多边形 + 4 像素白边、不画蓝框（与标注初稿的裁法相同）。

## 5. 提示词

在 `revrender.recognize_lines` 里加两个条件，沿用它的系统提示（`SYSTEM`）和基本要求（`SKELETON`），后面追加：

- **`boxed_read`**（R、B、E\*、E^p1、E^syn 用）追加：
  > 只转写蓝色框里学生原来写的内容，框外的内容不要输出。框里的字上可能有划线，也可能划线已经被去掉：有划线时，读出划线下面原来写的字，不要输出划线本身。
- **`boxed_marked`**（M\*、M^p1、M^syn 用）在上一句之前再加：
  > 图中红色的笔画是划线（作废记号），不是学生写的字；黑色的笔画是学生写的字。

要点：

- 所有版本用**同一句**主体提示，只有标记版本多一句"红色是划线"，避免提示词本身造成差异。
- 两个条件都读行包的 `images['raw']`（每个"处 × 版本 × 范围"在行包里是一行，见 §10）。
- 解码：`temperature 0`、种子 42、`max_new_tokens 256`、每次请求一张图；输出取 `<transcription>` 内的文字（`reading_of` 已实现）。
- `recognize_lines` 现在把 `max_model_len` 写死为 4096，整题图在 InternVL 这类分块模型上会超。**新增 `--max-model-len` 参数**（默认仍 4096，本实验用 8192），并在 manifest 里记录每个请求的图像尺寸。

## 7. 指标

记某处的人工答案为 `text`、模型读数为 `reading`。

| 指标 | 定义 | 实现 |
|---|---|---|
| **读回率**（主指标） | 答案中非 `?` 字符被最小编辑对齐保留下来的比例，按处等权平均 | `revrender.eval.revision_boxes.held`（底层 `eval.coverage.prepare` + `alignment`） |
| 严格全对率 | 规范化后读数与答案完全相同的比例；答案含 `?` 的处不计入分母 | `prepare(text) == prepare(reading)`，同 `revision_boxes.read` |
| 全部读到率 | 读回率 = 1 的比例 | 同上 |
| 多读率 | 读数中没有对齐到答案的字符数 ÷ 答案字符数（看整行 / 整题时读进了框外内容、或编造） | 用 `alignment` 的 `kept_y` 计算 |
| 空读率 | 读数为空或 `[空]` 的比例 | — |

- **规范化**：先确认 `prepare` 对 `$\frac{1}{2}$` 与 `\frac{1}{2}`、`$x$` 与 `x`、全角半角、`\times` 与 `×` 等是否给出相同结果。不一致的写进测试并在报告里说明；本轮**不改** `prepare`（改了会和之前的统一评测不可比）。
- **汇总**：每个 模型 × 集合 × 版本 × 范围 一组数。
- **配对比较与置信区间**：任何两个条件之间比较时，按处配对相减；用**按作答图聚类的自助法**（以作答图为单位重抽样，10,000 次，种子 42）给出平均差的 95% 区间。严格全对另做 McNemar 检验。
- **分组**：按 `annotationMode`（erase / keep）、划线占比三分位、答案长度（≤3 / 4–8 / >8 个字符）、是否含公式、训练 / 验证、是否用户新增框分别报告主要比较（R vs E\* vs M\*）。

## 8. 预先登记的判定规则

在看到任何读数之前，把下面的阈值写进配置文件并记哈希；之后不得改动。判定只用 P、主模型 4 个、范围 S1（D5 除外）；"成立"要求 4 个主模型中 **至少 3 个**满足条件。

| 编号 | 问题 | 条件 | 结论 |
|---|---|---|---|
| D1 | 问题存在 | R 的读回率 < 0.65 且严格全对率 < 0.35 | 成立 → H1 |
| D2 | 分离是瓶颈 | E\* − R ≥ +0.15，且区间下界 > 0 | 成立 → H2 |
| D2′ | 瓶颈在识别 | E\* − R < +0.05 | 成立 → 方向改为"用我们的数据微调 VLM" |
| D3 | 保留优于擦除 | M\* − E\* ≥ +0.03，且区间下界 > 0 | 成立 → "标记 / 注入"方向 |
| D3′ | 擦除优于保留 | M\* − E\* ≤ −0.03，且区间上界 < 0 | 成立 → "分离后擦除"方向 |
| D4 | 现有分离的差距 | 报告 E\* − max(E^p1, E^syn) 与 M\* − max(M^p1, M^syn) | 不设门槛，作为方法提升空间 |
| D5 | 整题上下文 | 在 R 和 E\* 上分别算 [(S3 − S1) − (S3 − S1 在 B 上的值)] ≥ +0.05 | 成立 → 整题输入有用；为负 → 局部更好 |

D2 与 D2′ 都不成立时记为"部分成立"；D3 与 D3′ 都不成立时记为"不分胜负"，方法默认选更简单的擦除路线，标记 / 注入留作消融。

## 9. 偏差与对照

1. **起稿偏差（最重要）**：P 的文字是用户在模型初稿上改出来的。最终使用的初稿是 Qwen3-VL-32B-FP8 读"理想擦除 + 只留多边形"小块（相当于 E\* × S0）得到的；更早的初稿是 32B 读原图（raw_struck）。V 的初稿是 32B 读原图。所以 **32B 不进任何判定**，只单独报告。另外报告"用户新增框"（31 处，初稿为空或少）与其余区域的对比，作为偏差的旁证。
2. **猜测下限**：B（全部涂白）在每个范围上的读回率，表示模型不看原字、只靠上下文能"猜对"多少；D5 已扣除。
3. **泄漏**：不用真实精修微调过的框内模型（§3）。被测的 VLM 都没有在这些数据上训练过。
4. **测试集隔离**：构建时用书写者划分复核（§2.1），发现测试书写者立即报错。
5. **其他修改**：只处理目标区域，同页其他划线保持原样；整行 / 整题里看到其他划线是正常的。
6. **标签噪声**：标签是单人标注，没有双人一致性。报告里写明；若时间允许，可请用户复查随机 20 处，记录改动比例（另行安排，不影响本轮）。

## 12. 第二阶段（另行启动）：读对被划内容对教育分析有多大帮助（H4）

本轮不做，记下设计以便衔接。

- **标签**：每处 3 项。被划内容对不对（对 / 错 / 不确定或不适用）、修改后对不对（同上）、修改类型（纠错 / 改错 / 错改错 / 重抄或格式 / 放弃思路 / 其他）。由模型对照标准答案（§2.4）和整份作答起草，**用户逐条确认**，记录用户改了多少条。
- **实验**：让同一个判题模型分别在三种输入下判断这 3 项：(a) 只给整题原图；(b) 整题原图 + 人工被划文字；(c) 整题原图 + 本轮最好条件下模型读出的被划文字。比较与确认标签的一致率（准确率、宏 F1）。
- **判定**：(b) − (a) ≥ +0.10 → "读出被划内容"是教育分析的瓶颈，应用部分成立；(c) 落在 (a)、(b) 之间的位置就是方法在应用上的价值。
